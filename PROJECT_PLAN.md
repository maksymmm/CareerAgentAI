# CareerAgent AI Roadmap

## Current release boundary

The eight autonomous-core units in `docs/exec-plans/active/autonomy.md` are implemented.
That completion applies to the backend core, with fake application, communication,
and calendar providers. It does not complete all phases of this long-term roadmap.
`SPEC.md` defines the current release contract.

Remaining product work includes a candidate-facing dashboard and approval interface,
real application/email/calendar adapters and their sandbox verification, a deployable
service composition, and public-beta validation. Web/mobile delivery and cloud
operation are not established by a passing core test suite.

The foundation checkboxes below now reflect the implemented backend. UI remains open.
